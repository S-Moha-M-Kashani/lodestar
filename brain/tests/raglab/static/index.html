What the numbers said last time (measured on this fixture, 2026-07-29 — re-run to confirm)
  • The embedder decides everything else. The brain's current default (ascii-hash) scores 0.014 session recall — its tokeniser is [a-z0-9]+, so Farsi embeds to the zero vector. Unicode character n-grams take it to 0.386; a multilingual transformer to 0.612.
  • Hybrid BM25 + dense with RRF is the biggest retrieval win (0.386 → 0.546 recall; single-hop 0.57 → 0.85). Lexical finds the rare literal, dense finds the paraphrase.
  • Semantic chunking pays in quote recall, not session recall — better boundaries change what is inside the chunk (quote recall 0.471 → 0.489, precision 0.191 → 0.243, pattern questions 0.11 → 0.26).
  • Only an LLM gate can abstain honestly. The lexical gate needs a 0.6 threshold to refuse 6 of 8 unanswerable questions, and there it wrongly refuses 52% of answerable ones. The LLM gate at 0.4 refuses 5 of 8 with 3% false refusals, and improves precision 0.34 → 0.59 and MRR 0.70 → 0.77.
  • Offline RAGAS context metrics are length-sensitive (whole-string similarity): they fell by half when chunks got longer even as quote recall rose. Compare them only within similar chunk sizes; the judged metrics on the same retrieval read 0.65 context recall against their 0.30.
